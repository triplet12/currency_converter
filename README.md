# Currency Converter

Консольный конвертер валют по актуальным курсам. Конвертирует суммы между любыми из ~160 валют, показывает таблицу курсов и хранит историю конвертаций. Курсы кешируются на диске, поэтому повторные запуски не обращаются к сети, а при отсутствии интернета программа использует последние сохранённые курсы.


## Возможности
 
- Конвертация между любыми валютами (например, EUR → RUB)
- Таблица курсов относительно выбранной валюты
- История конвертаций с выводом последних записей и очисткой
- Кеш курсов на диске со сроком жизни до следующего обновления курсов в API
- Работа без интернета на последних сохранённых курсах
- Повторные попытки при сбоях сети

## Установка
 
Нужен Python 3.10 или новее и Git.
 
```bash
git clone https://github.com/triplet12/currency_converter.git
cd currency_converter
python -m venv venv
```
Активация виртуального окружения:
 
```bash
venv\Scripts\activate          # Windows
source venv/bin/activate       # Linux, macOS
```
 
Установка вместе с зависимостями:
 
```bash
pip install -e ".[dev]"
```

Команда установит пакет в режиме разработки, библиотеку `requests`, мою библиотеку [decorators_kit](https://github.com/triplet12/decorators_kit) и `pytest` для тестов.


## Использование
 
### Конвертация
 
```console
$ python -m converter convert 100 USD RUB
100.00 USD = 8141.60 RUB
Курс: 1 USD = 81.4160 RUB, обновлён 2026-11-04
 
$ python -m converter convert 50 eur rub
50.00 EUR = 4556.39 RUB
Курс: 1 EUR = 91.1278 RUB, обновлён 2026-11-04
```
 
Коды валют можно писать в любом регистре.
 
### Курсы валют
 
```console
$ python -m converter rates USD --only RUB EUR CNY
Курсы для 1 USD (обновлены 2026-11-04):
CNY        6.6840
EUR        0.8934
RUB       81.4160
```
 
Без `--only` выводятся все доступные валюты.
 
### История
 
```console
$ python -m converter history --last 2
2026-11-07 14:03    50.00 EUR  →  4556.39 RUB
2026-11-07 14:03    100.00 USD  →  8141.60 RUB
 
$ python -m converter history --clear
История очищена.
```
 
По умолчанию показываются 10 последних записей, начиная с самой новой.

## Тесты
 
```bash
python -m pytest
```
 
Тесты не обращаются к сети: логика конвертации проверяется на заданных вручную курсах, разбор ответа API — на сохранённом настоящем ответе (`tests/data/usd.json`), работа с файлами — во временных папках.
